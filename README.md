# Verificador de Packing v1.1

PWA estática para comparar códigos de etiquetas con un Packing List Excel o CSV.

## Publicar en GitHub Pages

Sube el contenido de la carpeta `github-pages` a la raíz del repositorio o a la
rama configurada para Pages. La aplicación requiere HTTPS para utilizar la cámara.

## Uso

1. Abre la URL publicada.
2. Carga el Packing List.
3. Confirma la hoja, fila de encabezados y columna objetivo.
4. Escanea o ingresa el código.
5. Registra las fotografías y exporta la evidencia en ZIP.

Los Packing List y fotografías se procesan localmente en el dispositivo.
